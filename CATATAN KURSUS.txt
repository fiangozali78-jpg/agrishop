1. promt website 1

posisikan kamu adalah seorang web developer, tugas kamu membuat website menggunakan HTML, CSS dan JS serta tailwind CSS + play cdn supaya tampilan website yang responsive. saya ingin membangun website toko online yang menjual produk segala jenis produk pertanian. saya ingin nuansa websitenya modern, stylish dan responsive serta nyaman digunakan oleh user. buatkan saya struktur folder project lengkap beserta kodenya. saya ingin website saya menggunakan 1 index.html terlebih dahulu. tambahkan button CTA di setiap section dan tambahkan flying button untuk chat ke WhatsApp. buatkan promt akurat supaya saya bisa menggunakannya ke beberapa gen AI lainnya
